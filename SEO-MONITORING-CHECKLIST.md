## 2) Weekly SEO Checks (15-30 min)

### A. Indexing + Crawl Health (Search Console)

- [ ] Pages indexed are stable or increasing
- [ ] No new "Page is not indexed" spikes
- [ ] No critical issues in Page indexing report
- [ ] No sudden increase in crawl errors

If an issue appears:
- Note affected URL(s)
- Request indexing after fix
- Re-check next week

### B. Performance by Query (Search Console)

Filter by last 7 days and compare to previous 7 days.

Track these query groups:
- "photo booth rental toronto"
- "photo booth rental barrie"
- "photo booth rental vaughan"
- "photo booth rental brampton"
- "photo booth rental mississauga"
- "wedding photo booth [city]"
- "corporate photo booth [city]"

For each group, record:
- [ ] Clicks
- [ ] Impressions
- [ ] Average position
- [ ] CTR

### C. Landing Page Performance (GA4 + Search Console)

Track page-level movement for:
- / (homepage)
- /toronto.html
- /barrie.html
- /vaughan.html
- /brampton.html
- /mississauga.html

For each page, record:
- [ ] Organic sessions
- [ ] Engaged sessions
- [ ] Conversions
- [ ] Conversion rate

### D. Google Business Profile Activity

- [ ] Calls this week
- [ ] Website clicks this week
- [ ] Messages/leads this week
- [ ] New reviews count this week
- [ ] Posted at least 1 photo or update

## 3) Core Web Vitals Check (Weekly quick check, Monthly deep check)

### Weekly quick check

- [ ] Run PageSpeed Insights on homepage + 1 city page
- [ ] No major regressions in mobile performance
- [ ] LCP remains stable (target: under 2.5s where possible)
- [ ] CLS remains low (target: under 0.1)

### Monthly deep check

- [ ] Lighthouse run on all core pages
- [ ] Compare against last month and log trend
- [ ] Flag any score drop > 10 points

---

## 4) Rich Results + Schema Validation (Biweekly)

- [ ] Test homepage in Rich Results Test
- [ ] Test all city pages in Rich Results Test
- [ ] No invalid schema items
- [ ] Fix warnings that affect eligibility (FAQ, LocalBusiness, Service, Breadcrumb)

## 6) Monthly SEO Review (60 min)

### KPI Scorecard

Record this month vs last month:

- [ ] Organic sessions: ______ vs ______
- [ ] Organic leads (form + calls + email clicks): ______ vs ______
- [ ] Leads from city pages: ______ vs ______
- [ ] Avg ranking for primary city terms: ______ vs ______
- [ ] Google Business calls/clicks: ______ vs ______

### Decision Rules

- If impressions up but CTR down:
  - Update title + meta description on weak pages
- If clicks up but leads flat:
  - Improve CTA clarity and contact form section copy
- If one city page outperforms others:
  - Replicate its structure/content pattern to weaker city pages
- If rankings stagnate for 6+ weeks:
  - Publish new city-intent content and secure local backlinks

## 8) Daily SEO Checklist (20 Minutes)

Use this every day to keep rankings and lead flow moving.

### Monday (Performance + Priorities)

- [ ] Open Search Console and compare last 7 days vs previous 7 days.
- [ ] Check top 5 target query groups:
  - photo booth rental toronto
  - photo booth rental barrie
  - photo booth rental vaughan
  - photo booth rental brampton
  - photo booth rental mississauga
- [ ] Note 1 page with high impressions + low CTR.
- [ ] Choose 1 optimization task for the week.

Time target: 20 min

### Tuesday (Content Improvement)

- [ ] Improve one section on one city page (80-150 words).
- [ ] Add one FAQ question from a real client objection.
- [ ] Add one CTA sentence near booking/contact.
- [ ] Add one internal link to another relevant city/service page.

Time target: 20 min

### Wednesday (Authority + Links)

- [ ] Send 3 local outreach messages (venue/planner/DJ/photographer).
- [ ] Follow up on 2 previous outreach messages.
- [ ] Add 1 partner mention/case mention to a relevant page.
- [ ] Check one citation listing for NAP consistency.

Time target: 20 min

### Thursday (Google Business Profile)

- [ ] Post 1 GBP update (photo + short caption + CTA).
- [ ] Upload 2-3 fresh event photos.
- [ ] Respond to any new reviews/messages.
- [ ] Request 2 new reviews from recent clients.

Time target: 20 min

### Friday (Conversion + Wrap-up)

- [ ] Check GA4 leads from organic traffic this week.
- [ ] Identify 1 page with traffic but weak conversion.
- [ ] Improve one conversion element:
  - headline clarity
  - CTA wording
  - trust proof (review snippet/event count)
- [ ] Write weekly summary using your template.

Time target: 20 min

### Daily 3-Minute Quick Check (Optional)

If you only have 3 minutes:
- [ ] Check Search Console for major drops/errors.
- [ ] Check for new GBP reviews/messages.
- [ ] Log one next action for tomorrow.

### Rules to Keep It Effective

- Do only one meaningful task per day.
- Do not skip tracking: if it is not measured, it will not improve.
- Prioritize pages/queries already getting impressions first.
- Keep a simple weekly score: completed days out of 5.

## 9) 10-Minute SEO Checklist (Busy-Day Version)

Use this when your day is packed. The goal is consistency, not perfection.

### Daily Core (10 Minutes Total)

#### Step 1 (2 min): Health Check

- [ ] Open Search Console and confirm no major indexing/crawl spikes.
- [ ] Check if any top city query dropped sharply.

#### Step 2 (3 min): One Micro Optimization

Do only one:
- [ ] Improve one title/meta description on a page with high impressions + low CTR.
- [ ] Add one internal link from one city page to another relevant page.
- [ ] Add one FAQ question/answer based on a recent client question.
- [ ] Improve one CTA sentence near inquiry/contact section.

#### Step 3 (3 min): Local Trust Signal

Do only one:
- [ ] Post one Google Business Profile update.
- [ ] Upload one recent event photo to GBP.
- [ ] Send one review request to a recent client.
- [ ] Follow up with one local partner for backlink/collab.

#### Step 4 (2 min): Log + Next Action

- [ ] Write one sentence: what changed today.
- [ ] Write one sentence: what you will do tomorrow.

### Weekly Minimum Targets (using 10-minute mode)

- [ ] 3 micro on-page optimizations completed
- [ ] 2 GBP updates/photos posted
- [ ] 3 review requests sent
- [ ] 2 partner outreach/follow-ups sent
- [ ] 1 weekly KPI check completed

### What to Prioritize First (if uncertain)

1. Pages already getting impressions in Search Console
2. City pages with lowest CTR
3. Queries close to page 1 (positions 8-20)
4. Actions that improve trust (reviews, photos, proof)

## 10) 30-Day Local SEO Execution Plan

Business: YM Event Vendors (Photo Booth Rental)
Primary Markets: Toronto, Barrie, Vaughan, Brampton, Mississauga
Goal: Increase qualified organic leads from Google

### KPI Targets (30 Days)

- Organic leads (form + call + email click): +20%
- City-page organic sessions: +15%
- Average position improvement for city terms: +2 to +5 spots
- Google Business Profile actions (calls/clicks): +15%
- New Google reviews: 8 to 12

### Week 1: Foundation + Quick Wins

#### 1) Search Console + Measurement

- Verify all city pages are indexed and request indexing if needed.
- In Search Console, bookmark these query groups:
  - photo booth rental toronto
  - photo booth rental barrie
  - photo booth rental vaughan
  - photo booth rental brampton
  - photo booth rental mississauga
- In GA4, confirm conversion events are firing:
  - form submit
  - phone click
  - email click

#### 2) City Page Content Refresh (No redesign)

For each city page, add:
- 1 short “Recent Events in [City]” section (80-120 words)
- 1 “Best For” section (weddings/corporate/birthdays)
- 1 stronger CTA paragraph above contact link

#### 3) Google Business Profile (GBP)

- Post 2 updates this week:
  - Post #1: Wedding-focused, Toronto/Barrie mention
  - Post #2: Corporate-focused, GTA mention
- Upload 10 real event photos (mix of setups, prints, guests)

#### 4) Reviews

- Send 10 review requests to recent clients.
- Ask for city + event type in review wording naturally.

Deliverables by end of Week 1:
- 5 refreshed city pages
- 2 GBP posts
- 10 review requests sent

### Week 2: High-Intent Content + Internal Linking

#### 1) Publish 2 Intent Pages

Create and publish:
- "Photo Booth Rental Cost in Toronto & GTA (2026 Guide)"
- "Wedding Photo Booth Ideas for Toronto & Barrie Venues"

Each page should include:
- clear H1/H2 structure
- city mentions naturally
- FAQ block
- clear CTA to contact section

#### 2) Internal Linking Push

Add contextual links from:
- homepage to each city page
- each city page to one relevant blog/guide
- each guide back to city pages

Anchor examples:
- photo booth rental toronto
- wedding photo booth barrie
- corporate photo booth mississauga

#### 3) GBP + Reviews

- Post 1 new GBP update with before/after booth setup shots.
- Send 10 more review requests.

Deliverables by end of Week 2:
- 2 new high-intent content pages
- internal links added across all key pages
- +1 GBP post, +10 review requests

### Week 3: Local Authority (Backlinks + Citations)

#### 1) Backlink Outreach (Quality over quantity)

Contact 20 local partners:
- wedding planners
- venues
- DJs
- photographers
- decorators

Ask for:
- preferred vendor mention
- portfolio link
- local partner listing

Target result: 3-5 live local links.

#### 2) Citation Consistency

Check and update NAP consistency on:
- Google Business Profile
- Bing Places
- Apple Maps
- Yelp
- YellowPages
- Wedding directories

#### 3) Publish 1 Local Venue Page

Create one page:
- "Best Photo Booth Setup for [Top Venue/Area] Events"

Include:
- logistics tips
- ideal backdrop choices
- best booth package by guest count
- CTA

Deliverables by end of Week 3:
- 20 outreach messages sent
- 3-5 backlinks in progress/live
- 1 venue-focused page published

### Week 4: Conversion Optimization + Scale What Works

#### 1) CRO Pass on Top 3 Landing Pages

Using GA4 + Search Console data, optimize:
- meta title/description on pages with high impressions and low CTR
- CTA copy on pages with traffic but low lead conversion
- trust elements (review snippets, event counts, response-time promise)

#### 2) Expand Winning Topic

Pick best-performing city/topic from Weeks 1-3 and publish 1 follow-up page:
- Example: "Corporate Photo Booth Toronto: What to Include in Your Event Package"

#### 3) Monthly Review + Next-Month Plan

Record in checklist:
- traffic changes by city page
- query ranking movement
- total organic leads
- GBP action growth

Decide next month priorities:
- 2 more venue pages
- 1 pricing/FAQ update
- ongoing backlink outreach cadence

Deliverables by end of Week 4:
- top pages conversion-improved
- 1 additional high-intent page
- monthly KPI report completed
