# SEO Monitoring Checklist (Weekly + Monthly)

Use this checklist every week to track what matters: rankings, visibility, and lead generation.

## 1) One-Time Setup (if not done yet)

- [ ] Google Search Console verified for https://ymeventvendors.ca
- [ ] Sitemap submitted: https://ymeventvendors.ca/sitemap.xml
- [ ] GA4 installed and collecting data
- [ ] Conversions configured in GA4:
  - [ ] Contact form submit
  - [ ] Click-to-call (phone tap)
  - [ ] Email click
- [ ] Google Business Profile connected and fully completed

---

## 2) Weekly SEO Checks (15-30 min)

### A. Indexing + Crawl Health (Search Console)

- [ ] Pages indexed are stable or increasing
- [ ] No new "Page is not indexed" spikes
- [ ] No critical issues in Page indexing report
- [ ] No sudden increase in crawl errors

If an issue appears:
- Note affected URL(s)
- Request indexing after fix
- Re-check next week

### B. Performance by Query (Search Console)

Filter by last 7 days and compare to previous 7 days.

Track these query groups:
- "photo booth rental toronto"
- "photo booth rental barrie"
- "photo booth rental vaughan"
- "photo booth rental brampton"
- "photo booth rental mississauga"
- "wedding photo booth [city]"
- "corporate photo booth [city]"

For each group, record:
- [ ] Clicks
- [ ] Impressions
- [ ] Average position
- [ ] CTR

### C. Landing Page Performance (GA4 + Search Console)

Track page-level movement for:
- / (homepage)
- /toronto.html
- /barrie.html
- /vaughan.html
- /brampton.html
- /mississauga.html

For each page, record:
- [ ] Organic sessions
- [ ] Engaged sessions
- [ ] Conversions
- [ ] Conversion rate

### D. Google Business Profile Activity

- [ ] Calls this week
- [ ] Website clicks this week
- [ ] Messages/leads this week
- [ ] New reviews count this week
- [ ] Posted at least 1 photo or update

---

## 3) Core Web Vitals Check (Weekly quick check, Monthly deep check)

### Weekly quick check

- [ ] Run PageSpeed Insights on homepage + 1 city page
- [ ] No major regressions in mobile performance
- [ ] LCP remains stable (target: under 2.5s where possible)
- [ ] CLS remains low (target: under 0.1)

### Monthly deep check

- [ ] Lighthouse run on all core pages
- [ ] Compare against last month and log trend
- [ ] Flag any score drop > 10 points

---

## 4) Rich Results + Schema Validation (Biweekly)

- [ ] Test homepage in Rich Results Test
- [ ] Test all city pages in Rich Results Test
- [ ] No invalid schema items
- [ ] Fix warnings that affect eligibility (FAQ, LocalBusiness, Service, Breadcrumb)

---

## 5) Link + Reputation Signals (Weekly)

- [ ] 1 new Google review requested from recent client
- [ ] 1 local backlink outreach sent (venue/planner/DJ/photographer)
- [ ] NAP consistency spot-check on 2 listings/directories
- [ ] 1 Google Business Profile post published

---

## 6) Monthly SEO Review (60 min)

### KPI Scorecard

Record this month vs last month:

- [ ] Organic sessions: ______ vs ______
- [ ] Organic leads (form + calls + email clicks): ______ vs ______
- [ ] Leads from city pages: ______ vs ______
- [ ] Avg ranking for primary city terms: ______ vs ______
- [ ] Google Business calls/clicks: ______ vs ______

### Decision Rules

- If impressions up but CTR down:
  - Update title + meta description on weak pages
- If clicks up but leads flat:
  - Improve CTA clarity and contact form section copy
- If one city page outperforms others:
  - Replicate its structure/content pattern to weaker city pages
- If rankings stagnate for 6+ weeks:
  - Publish new city-intent content and secure local backlinks
